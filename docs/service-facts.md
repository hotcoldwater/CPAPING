# CPAPING 서비스 소개 자료 (홍보 원고용 사실 정리)

원고를 쓸 때 근거로 쓰는 사실·수치·링크 모음. 수치는 **2026-09-10 실측**이며, 홍보 전에 아래
"수치 갱신" 절의 조회로 다시 채운다. 사이트에 홍보 글은 쓰지 않는다(운영자 결정) — 이 문서는 외부 원고용.

## 한 줄

한국공인회계사회 구인 게시판(수습CPA·CPA)을 **1분마다** 확인해 새 공고를 메일로 보내고,
회계법인 **254곳**의 재무·인력 자료와 댓글·게시판을 한곳에 모은 **무료** 사이트.
운영자 개인이 만들었고, **한국공인회계사회 공식 서비스가 아니다.**

- 주소: https://cpaping.com
- 문의: contact@cpaping.com
- 비용: 무료, 광고 없음

## 기능

- **새 공고 알림** — 수습 정규직 · 수습 파트타임 · 경력을 각각 켜고 끔. 지역(전국·수도권·지방) 선택.
  이메일 하나로 가입, 탈퇴 즉시 삭제.
- **공고 정리 페이지** — 마감·지역·고용형태·연차, 한공회 조회수와 오늘 증가분, 원문 버튼.
  본문과 담당자 연락처는 싣지 않고 원문으로 연결.
- **회계법인 페이지** — 매출·회계사 수·수습 채용 추이 차트(5개년), 상장사 감사 고객, 그 법인의 공고.
- **법인 비교표** — 254곳 정렬·검색, 댓글 수 표시.
- **댓글** — 공고·법인마다. 대댓글, 추천, 베스트 댓글(추천 10개 이상 상위 3개 고정), 신고 즉시 비공개.
- **자유게시판** — 글·댓글·추천·신고.
- **로그인** — Google, 이메일. 카카오·네이버는 준비 중.
- **수습 공고는 빅4 제외**(빅4는 자체 채용), **경력 공고는 빅4·일반기업 포함**.

## 대상별 강조점

**준비생·합격생**
- 새로고침 안 해도 새 공고가 1분 안에 메일로 온다.
- 지원 전에 그 법인이 매출 얼마인지, 수습을 몇 명 뽑는지 본다.
- 공고 밑 댓글로 물어본다. 읽는 데는 가입이 필요 없다.

**현직자**
- 경력 공고만 걸러서 본다(직원 공고 제외). 빅4 팀 단위 채용, 일반기업 회계사 채용 포함.
- 회계법인 254곳을 5개년 수치로 비교한다.

**공통**
- 이메일만 받고, 탈퇴하면 즉시 삭제. 원문은 한공회로 연결.

## 수치 갱신

홍보 직전에 아래로 다시 채운다(리포 루트에서).

```
.venv/bin/python - <<'PY'
import os, requests
from dotenv import load_dotenv; load_dotenv(".env")
U=os.environ["SUPABASE_URL"].rstrip("/"); K=os.environ["SUPABASE_SECRET_KEY"]; H={"apikey":K,"Authorization":f"Bearer {K}"}
g=lambda t,**p: requests.get(f"{U}/rest/v1/{t}", params=p, headers=H, timeout=30).json()
jp=g("job_postings", select="source,is_target"); print("수습 대상", sum(1 for p in jp if p["source"].endswith("trainee") and p["is_target"]), "· 경력 대상", sum(1 for p in jp if p["source"].endswith("cpa") and p["is_target"]))
print("법인", len(g("firms", select="id")), "· 재무", len(g("firm_financials", select="firm_id")), "· 구독 active", len(g("subscribers", select="id", status="eq.active")), "· 회원", len(g("profiles", select="user_id")))
PY
```
