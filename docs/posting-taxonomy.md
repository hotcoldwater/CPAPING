# 전체 채용 수집과 공개 분류

## 사용자 화면

- 탭: 전체 / 신입 CPA / 경력 CPA / 일반 채용.
- CPA 지원 자격과 경력 조건을 원문에서 판단한다. 원문 CPA 메뉴만으로 CPA 자격을 단정하지 않는다.
- 신입·경력 동시 모집과 CPA 경력 무관은 두 탭에 나타나며 전체에는 한 번만 표시한다.
- CPA 우대만 있는 자리는 일반 채용 + CPA 우대. 첨부에만 자격이 있는 등 불명확하면 전체에 남기고 `taxonomy_needs_review`로 검토한다.
- 회사·기관, 지역, 근무방식은 기본 필터. 경력, 계약형태, 지원 방식, 양식, 원문 분류는 상세 조건이다. 한 조건 안에서는 OR, 다른 조건끼리는 AND이다.
- 마감/내려간 공고도 보존하며 '마감 공고 포함'으로 확인한다. 마감일 미기재는 누락시키지 않는다.
- 목록과 상세의 라벨은 동일한 공개 분류를 사용한다. 풀타임은 정규직으로 바꾸지 않는다.
- 같은 본문 해시 또는 동일 조건의 확인된 재공고는 묶고 이전 공고 링크를 제공한다. 회사/제목/지역/고용형태가 다른 공고는 함부로 합치지 않는다.

## 실제 한공회 구조 (2026-09-15 확인)

| 메뉴 | 실제 요청 | 세부 탭 |
|---|---|---|
| CPA | `/home/jobOffrSrchGnrl/list.face?ijJobSep=1` | ijCoSep 1,2,3,4,5,8 |
| 일반 | 같은 경로, `ijJobSep=-1` | ijCoSep 1,2,3,4,5,8 |
| 수습CPA | `/home/jobOffrSrchNewGnrl/list.face` | ijEmpSep 5,6,7 |
| 한국공인회계사회 | `/board/list.brd?boardId=jobInfoKicpa` | 전체 날짜 |

회사 탭은 회계법인/회계사무소/공공기관/일반기업/헤드헌터/한국공인회계사회이다. '일반기업'도 포함한다.
기본 일반 목록은 회계법인 탭만 반환한다. `ijCoSep=all`은 유효한 전체 조건이 아니므로 사용하지 않는다.

각 탭에서 페이지 전체 건수와 고유 ID 수가 일치해야 저장/내려감 판정을 진행한다. 읽을 수 있는 과거 목록에 날짜 제한을 두지 않는다. 원문에서 이미 삭제된 과거 글은 복구할 수 없으며 기존 DB 사본을 보존한다.

CPA와 일반은 같은 상세 ID 공간을 쓴다. 기존 `source=kicpa:cpa` 키를 유지하면서 `source_categories`에 실제 메뉴를 저장한다. 두 메뉴에서 같은 ID가 나오면 합집합으로 저장하여 중복 행/URL을 만들지 않는다. 수습과 자체 채용은 별도 물리 출처다.

## 기존 발송 범위 보존

공개 목록은 `is_target`을 사용하지 않는다. 새 `recruitment_categories` 등은 검색용이며 알림/자동 지원 조건과 독립적이다.

- 기존 사용자 설정, 규칙 버전, 지원 기록, 발송 이력은 변경하지 않는다.
- 새로 추가되는 물리 탭의 공고를 기존 알림 스위치에 자동으로 편입하지 않는다. 신규 CPA/일반 행의 기존 알림 범위는 이전 실제 수집 범위(일반 메뉴의 회계법인 탭)를 유지한다. 전체 공개 분류에 맞춘 알림 설정 확대는 별도 작업이다.
- 업로드 이력서 자동 지원은 기존 수습 출처 + entry/cpa/is_target + 선택한 Full/Part Time 검증을 계속 사용한다.
- 과거 누락 공고를 추가할 때 `is_target=false`로 저장하고 관리자 알림 대기에서도 제외한다. 기존 행의 `is_target`, `audience`, `posting_type`, `first_seen_at`, `notified_at`은 변경하지 않는다.

## 변경 및 검증

DB: `024_posting_taxonomy.sql` (추가 컬럼만, 반복 실행 가능).
수집: `fetch_board_inventory`; 공개 분류: `crawler/taxonomy.py`; 공유 표시: `web/posting-taxonomy.js`.
기존 본문 갱신 시 공개 분류도 갱신하되 발송 필드는 보존한다.

최초 대조: 수습 48, CPA 241, 일반 84, 자체채용 0 → 접근 가능한 고유 공고 373. 기존 142 중 108건이 현재 목록에 존재하여 신규 265건을 추가, 총 407건 보존.

`backfill-posting-taxonomy.py --cache PATH`는 준비한 공개 원문 캐시와 DB를 비교해 변경안을 작성한다. `--apply`는 검토한 분류를 적용하며, 동시 크롤러가 먼저 삽입한 행은 덮어쓰지 않는다. `--archive PATH`로 기존 상세 HTML 사본을 선택적으로 보강할 수 있다.

검증은 수집 페이지 누락/중복, 자격 필수/우대/연도 오탐, 경력 무관, 원문 참조만 있는 조건, 필터 다중 선택/해제, 빈 결과, 마감일 없는 공고, 재공고/고용형태 구분, 기존 발송 범위와 SQL 이력 보존을 포함한다. UI 동작은 JSDOM으로 확인하며 실제 브라우저 시각 검증은 별도로 필요하다.
