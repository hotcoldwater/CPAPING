# 신입 회계사 공고와 지역별 탐색

2026-09-16 사용자 요청으로 공개 화면과 알림을 신입 회계사가 지원할 수 있는 공고로 축소했다.

## 사용자 화면

- 필터는 근무형태(전체 / 풀타임 / 파트 / 인턴)와 지역(전체 / 서울 / 경기 / 지방) 두 줄이며 선택 조건은 AND로 적용한다. 경기에는 인천을 포함하며 툴팁으로 안내한다.
- 각 버튼의 건수는 검색·마감 포함과 다른 차원의 선택을 반영한다. 근무형태가 복수이면 해당 항목에 각각 나타나며, 미상은 근무형태 전체에서만 확인한다. 각 선택은 독립적으로 기억하고 조건 초기화 시 모두 전체로 되돌린다.
- 지역 미상·전국·해외 공고는 전체에서 확인한다. 여러 지역을 명시하면 해당 지역 탭 모두에 나타난다.
- 회사 유형, CPA 구분, 상세 조건 필터는 제거한다. 검색·정렬·마감 공고 포함은 유지한다.
- 신입·경력 동시 모집은 신입 지원이 가능하면 포함한다. 경력 전용과 일반 직원 모집은 제외한다.
- 수습기간이 있다는 사실은 신입 채용의 근거가 아니다. 실무수습 완료 후 추가 경력을 요구하면 경력 공고로 본다.
- CPA 자격자에게 경력 요건을 면제한다고 명시한 공고는 신입 지원이 가능하므로 포함한다.
- 목록·상세·관련 공고·법인별 공고·사이트맵은 같은 entry_cpa 조건을 사용한다.
- 최초 확인 시각을 표시하지 않으며 원문 등록일은 유지한다.

## 수집 자료와 알림

원문 게시판의 분류만으로 신입 지원 여부를 알 수 없으므로 기존 전체 원문 수집·보관은 유지하고 공개 및 알림 대상을 제한한다. 보관된 경력·일반 공고, 지원 기록, 이력서 파일은 삭제하지 않는다.

새 공고 알림은 수습/CPA 두 물리 게시판 모두 신입 지원 가능한 공고만 대상으로 한다. 기존 신입 풀타임·파트타임 수신 설정을 적용하고 경력직 스위치는 가입/알림/메일 설정 화면에서 제거한다. 경력직만 받던 사용자를 신입 알림에 임의로 가입시키지 않는다.

지원준비의 업로드 이력서 자동지원은 기존 수습 출처와 자격 검증을 유지한다. 새 이력서 작성 흐름은 이번 변경에 포함하지 않는다.

`reclassify-entry-postings.py --audit PATH`는 분류 변경과 범위 밖 기존 알림 대상 해제를 검토한다. `--apply`로 적용한다. 과거 수입 공고의 알림을 다시 활성화하지 않으며 메일을 발송하지 않는다.

## 수집 구조 및 검증

CPA/일반은 같은 상세 ID 공간으로 source=kicpa:cpa를 공유하고 실제 원문 메뉴는 source_categories로 보관한다. 수습CPA는 풀타임/파트타임/인턴십 탭을 확인한다. 목록 건수·고유 ID 수를 대조한 후에만 내려간 공고를 판정한다.

최초 전체 대조에서는 접근 가능한 공고 373건과 보관된 과거 공고 34건으로 총 407건을 확보했다. 공개 대상 수는 현재 분류·마감 여부·재공고 묶음에 따라 달라진다.

검증 항목: 신입·혼합·경력 전용·일반 구분, 수습 완료 조건, CPA 경력 면제 조건, 지역별 목록·검색·마감 포함, 관련 공고 범위, 알림 쿼리 범위, 과거 알림 재활성화 방지.
