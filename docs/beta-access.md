# Beta 화면 접근

게시판·지원준비·지원현황에 beta 표시를 붙인다. 게시판은 일반 회원에게 계속 열린다. 공고 목록과 상세에는 지원양식 유형·분석 상태·분석 근거를 표시하지 않는다. 원문·첨부파일·내부 분석·발송 처리와 기존 데이터는 유지한다.

지원준비·지원현황 및 공고의 지원하기 링크는 기본 비활성 상태다. 서버에서 확인한 관리자에게만 활성화하며, 직접 주소를 열어도 권한 확인 전 화면을 표시하거나 지원 데이터를 요청하지 않는다. 관련 API는 일반 회원에게 403을 반환한다. 계정 정보 및 메일 연결 해제는 그대로 사용할 수 있다.

Pages production의 CAREER_ADMIN_USER_IDS에 관리자 UUID를 쉼표로 구분해 설정한다. 현재 승인된 운영 계정 ohshsh00@gmail.com 한 개만 지정했다. 설정 누락·권한 확인 실패 시 접근을 닫고, 사용자 수정 가능한 프로필이나 메타데이터로는 권한을 부여하지 않는다. 이 설정은 화면/API 접근만 제어하며 기존 지원 데이터와 백그라운드 분석·발송 작업은 변경하지 않는다.
