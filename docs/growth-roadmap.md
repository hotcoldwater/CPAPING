# CPAPING 성장 실행 로드맵

기준일: 2026-09-11. 준비생·합격생·현직·경력·개업 회계사가 계속 이용하는 국내 최대 회계사 커뮤니티를 목표로 한다.

이 문서가 **앞으로의 실행 순서와 진행 상태의 기준**이다. README의 이전 Phase 번호는 개발 이력이며,
`plan-community.md`는 기존 설계와 결정의 참고 자료다. 충돌 시 이 문서의 새 결정이 우선한다.
기능 개발만으로 목표가 달성되는 것은 아니다. 배포·실사용 검증·운영·유입 실험을 함께 진행한다.

## 방향과 운영 원칙

- 첫 집중 대상은 첫 취업을 준비하는 합격생. 이후 수험과 현직 생활로 확장한다.
- 핵심 흐름: 공고 발견 → 법인 비교 → 지원 관리·자소서 → 면접·취업 → 경험 공유 → 후배 답변.
- 읽기는 공개하고, 저장·알림·작성처럼 개인 가치가 생기는 시점에 가입을 연결한다.
- 공시 수치·원문 사실·사용자 경험·AI 제안을 구분하고 출처와 기준일을 표시한다.
- 개인 자소서·지원 이력은 기본 비공개. 공개 후기는 별도 동의를 통해 받는다.
- 사용자 지시로 명시적으로 변경된 정책: **빅4 수습을 제외하지 않는다. 한공회 채용 공고 전체를 다룬다.**
- ‘전체’는 한공회의 구인(수습CPA)·구인(CPA) 두 채용 게시판을 뜻한다. 일반 공지·입찰은 별도 확장이다.
- 전체 수집과 전체 알림을 분리한다. 직원·미분류까지 받을 선택지를 만들되 기존 구독 조건을 자동으로 넓히지 않는다.
- 한공회 전체와 국내 채용 전체는 다르다. 법인 자체 채용 사이트는 이후 별도 출처로 추가한다.
- 기존 문서의 소속 공개·닉네임 정책은 유지하며, 인증과 소속 공개의 분리는 사용자 조사 후 설계한다.
- 외부 홍보 게시·메일·DM은 원고와 대상 목록을 준비한 다음 별도 발송 지시를 받아 실행한다.
- 한 번에 한 배포 단위씩 구현 → 검증 → 배포 결과 확인 → 상태 갱신. 로컬 테스트 통과를 실서비스 완료로 표시하지 않는다.

브라우저에서의 시각적 검증과 배포 후 신규 공고 관찰은 남아 있다.

## 이후 Phase의 세부 범위

### Phase 2 — 첫 이용자 확보

- 가입 CTA에서 가입 탭으로 바로 연결하고, 완료 후 원래 하던 행동으로 돌아온다.
- 개인 상태는 준비생·합격생·현직 중 선택할 수 있게 하되 불필요한 입력을 강제하지 않는다.
- 이벤트: 가입 시작/완료, 알림 설정 완료, 공고 원문 이동, 공고 저장. 민감한 원문·이메일은 이벤트에 담지 않는다.
- 현황 파악용 자료: 유입 채널, 첫 가치 경험률, 7일 재방문, 실제 오류 기록.
- 운영 산출물: 합격생 인터뷰 질문지, 고시반 공유 자료, 채널별 홍보 원고·UTM, 2주 실험 결과.

### Phase 3 — 지원 관리와 커뮤니티

- 관심→작성 중→지원 완료→면접 예정→결과. 실제 제출 여부는 사용자 확인으로 기록.
- 개인 메모·일정·자소서 버전은 기본 비공개. 관심 법인 2~4곳을 저장해 비교.
- 게시판 하나에 채용·수험·현직·자유 태그. 읽는 경험은 분산하지 않는다.
- 답변 알림·글 구독·미답변·해결 표시·비슷한 질문 검색을 우선한다.
- 운영자 선정 글을 사용자 추천과 구분. 기여자·공식 담당자·일반 인증 배지를 구분.

### Phase 4~5 — 자소서에서 제출 문서까지

- 첫 초안은 경험 2~3개·지원 법인/직무·강점·문항/분량으로 시작하고 부족한 재료만 추가 질문.
- 경험/스펙·페르소나·차별점·핵심 질문 답변을 한 번 저장하고 여러 지원에 재사용.
- 법인 자료는 공식 출처·공시·기준일과 함께 사용. 법인 전체 수치를 특정 팀의 사실로 단정하지 않는다.
- 문항별 경험 연결·문장 편집·버전 비교·허위 성과 생성 방지·타 법인명 잔존 검사·글자 수/바이트 검사.
- 자유양식부터 PDF와 편집 가능한 파일 지원. 파일명·한글 글꼴·표 넘침·인쇄·빈 필수 항목 검증.
- 지정 양식은 검수된 소수부터. 임의 업로드는 항목 추출→사용자 대응 확인→누락 입력→미리보기 순서.
- 자소서·이력서·지원 이력 화면은 세션 녹화 제외. 삭제·보유기간·외부 처리 범위 설계.
- 면접·취업 뒤 짧은 후기 요청. 개인 지원 내용이 자동 공개되지 않도록 분리.

### Phase 6~8 — 생애주기와 유입 확대

- 신입 첫 90일 자료, 직무별 질문, 경력 이동 사례로 취업 후 이용을 연결.
- 수험 일정은 공식 근거·확인일을 표시. 개정 사항은 확인하고 오래된 정보는 구분.
- 법인 데이터 기반 검색 콘텐츠·비교 공유 링크·채용 캘린더를 제작.
- 회계사 인증과 회사 소속 인증, 법인 공식 대표 권한을 구분. 인증 자료 최소 보유.
- 연봉·근무시간 자료는 연도·직급·직무·표본 수와 함께 집계하고 작은 집단은 공개하지 않는다.
- 기본 공고와 대화는 무료 접근 유지. 고급 문서·채용 지원의 지불 의사를 소규모 검증.
- 광고·후원 표시는 평가와 분리. 네이티브 앱·복잡한 포인트·대규모 실무 AI는 실수요 확인 후 검토.

## 측정 기준과 의사결정

기준선은 2026-09-10 내부 소개 자료의 구독자 28명·회원 7명이다. 실시간 지표나 회원 전환율로
해석하지 않는다. 분석 도구 설치와 핵심 행동 측정 완료도 구분한다.
