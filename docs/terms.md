# 이용약관 (확정본)

**운영자가 직접 작성한 본문이다. 법률 자문을 받지 않았다.** 이 파일이 원본이며
`web/terms.html` 이 이 내용을 게시한다. 내용을 고칠 때는 두 곳을 함께 바꾼다.

- 공고일 / 시행일: 2026년 9월 9일 (제1판)
- 게시 위치: https://cpaping.com/terms
- 회원·게시물·인증 조항(제4~10조)은 **회원 기능이 열리는 날부터** 적용된다. 그 전까지는
  서비스 이용(제3조)·면책(제12조)·준거법(제13조)만 살아 있다.

## 왜 지금 쓰는가

댓글을 열려면 게시판 운영자의 의무가 생긴다 — 권리침해 신고를 받으면 임시조치를 하고,
게시자에게 알리고, 결과를 통지해야 한다(정보통신망법 제44조의2 취지). 그 절차와 운영자의
삭제 권한, 이용자의 책임을 미리 적어 두지 않으면 첫 분쟁에서 근거가 없다.

## 이 약관이 코드에 요구하는 것

| 조항 | 구현 (회원 기능과 함께) |
|---|---|
| §4 만 14세 이상만 가입 | 가입 화면 동의 체크. 생년월일은 받지 않는다 |
| §4 닉네임 규칙 | 2~12자, 중복 불가, 운영자·법인 사칭 문구 금지 |
| §5 법인 소속 확인 | 로그인 이메일 도메인 = 법인 도메인이면 자동 부여. 도메인 표는 `firms` 에 둔다 |
| §5 합격자 인증 | 합격확인서는 비공개 저장소에 두고 **심사 완료 즉시 삭제**, 미심사 7일 자동 삭제. 남기는 값은 합격 연도·인증 여부·일시 |
| §6 운영자 삭제·비공개 | 운영자 역할이 모든 댓글을 숨기고 지울 수 있어야 한다 |
| §7 임시조치 | 신고된 댓글을 즉시 비공개로 돌리고 30일 안에 처리. 상태 필드로 기록 |
| §10 탈퇴 시 댓글 존치 | 계정·이메일은 지우고 댓글 작성자를 "탈퇴한 사용자" 로 바꾼다. **방침 §4 개정이 함께 필요** (회원 절 신설) |

> ⚠️ 개인정보처리방침에는 아직 "회원" 절이 없다. 로그인을 넣을 때 방침 제6판으로
> 계정 정보(이메일·닉네임·인증 정보·댓글)와 탈퇴 시 처리(댓글 익명화 존치),
> 합격확인서 일시 처리·즉시 파기를 넣어야 한다. 약관 §10 과 어긋나면 안 된다.

## 변경 이력

**2026-09-09 제1판** — 최초 제정. 운영자 표시는 방침과 같이 연락처만 적는다.
14세 미만은 가입할 수 없다. 탈퇴해도 댓글은 남기고 작성자를 익명화한다 — 대화 맥락에
구멍이 나는 것보다 낫다고 운영자가 결정했다. 뱃지는 법인(도메인 자동)·공식 계정(운영자
지정)·합격자(합격확인서 수동 심사, 서류 즉시 파기) 세 가지다.
