# 지원준비 · 지원현황 · 답장 결과 확인 (2026-09-15)

## 사용자 결정

- 메뉴는 **지원준비**. 최초 진입은 미등록 안내 또는 현재 저장된 요약이다.
- 시작/수정 시 첫 단계부터 작성. 작성 중 내용은 DB 임시 저장, 이어서 작성 가능.
- 화면에는 이력서 한 개만 사용. 업로드 목록 선택과 개별 삭제 UI 제거.
- 수정 중 새 업로드는 활성 규칙을 바꾸지 않는다. 최종 저장 시 교체하고 기존 발송 대기를 다시 검수한다.
- 업로드 원본 전부와 실제 발송별 `document_id`를 보관한다. 관리자 조회 UI는 후속 작업이다.
- 지원현황은 준비·검수·대기·발송·실패·취소를 한 표에서 조회하고 서버에서 필터/검색/페이지 처리한다. 상세 대화상자에서 검수·첨부·메일·결과를 관리한다.

## 저장과 동시 수정

SQL 022는 기존 SQL 014/016/017/019/021 다음에 적용한다. `career_resume_drafts`는 회원별 작성 내용, 시작 당시 규칙 버전, 임시저장 버전을 보관한다. 최종 저장은 같은 사용자 잠금 안에서 임시저장 버전과 활성 규칙 버전을 검사하고 임시저장을 정리한다. 초안은 동의 상태를 저장하지 않는다.

이전 이력서는 일반 화면에서 숨기지만 DB에서 삭제하지 않는다. `career_mail_deliveries.document_id`와 `career_reply_events.document_id`로 발송 당시 파일과 결과를 연결한다. 작업공간/회원 탈퇴에 따른 삭제는 기존 경로를 유지한다. 신규 테이블과 RPC는 일반 회원·익명 직접 접근을 차단한다.

## Gmail 답장

Gmail 연결에서 `gmail.send`와 `gmail.readonly`를 요청한다. 읽기 권한을 받은 계정만 `reply_read_enabled=true`로 저장한다. 기존 연결은 발송 기능을 유지하고 지원준비 → 수정하기 → 답장 확인 권한 연결에서 추가 동의를 받는다. 읽기 권한을 거절하고 발송만 허용해도 발송 연결은 유지한다.

기존 5분 작업에 `career.replies.process`를 연결한다. 실행당 시간/처리량 한도를 두고 오래 확인하지 않은 계정/지원부터 순환한다. 현재 연결된 발신 주소와 실제 발송 주소가 같은 실제 지원 메일만 확인한다. 테스트 메일은 자동 분류에서 제외한다.

- Gmail의 실제 보낸 메시지 ID → 대화 조회 → 원본 Message-ID를 참조하는 이후 답장만 연결.
- 발송·임시보관·스팸·휴지통 메시지 및 본인이 보낸 메일 제외.
- 원래 수신자와 발신자 일치, Gmail DMARC 통과 및 발신 도메인 일치를 확인한 경우에만 명확한 한국어 본문 문구를 자동 분류한다.
- 제목만으로 합격 판정하지 않는다. 인용문·전달문·HTML 인용·스크립트·첨부를 제외한다.
- 접수 확인, 서류합격, 서류불합격, 답장 확인 필요를 구분한다. 면접 일정만으로 서류합격을 추정하지 않는다. 명확하지 않거나 인증을 확인할 수 없으면 사용자 확인으로 남긴다.
- 동일 메시지는 한 번 기록한다. 오래된 답장이나 애매한 후속 답장은 명확한 결과를 낮추지 않는다. 상충하는 합격/불합격은 확인 필요로 돌린다.
- 사용자의 수동 정정은 자동 처리로 덮어쓰지 않는다. 모든 수정과 근거 본문 일부(2,000자 이내)를 지원별로 보관한다.

**범위:** 새로운 제목으로 별도 발송되어 원본 메일을 참조하지 않는 결과, 전화·문자 결과, 아직 인식하지 못하는 문구는 직접 입력/확인이 필요하다. 외부 AI 호출과 실제 테스트 지원 메일 발송은 포함하지 않는다.

Google의 읽기 권한 동의와 OAuth 앱 운영 상태는 실제 계정에서 추가 연결할 때 확인해야 한다. Google이 추가 검증을 요구하면 해당 콘솔 절차를 완료해야 한다.

## 검증

JSDOM으로 미등록/등록/작성 중/수정 취소/업로드/단계별 검증/최종 저장/검수 승인/HTML 무해화를 확인한다. PGlite로 파일 보관·원본 첨부 연결·초안/규칙 동시 수정·결과 변경 이력·다른 회원 차단·RPC 권한·표 필터/페이지를 확인한다. Python 모의 Gmail 메시지로 결과 분류·인용/자동회신/발신자/참조 연결·외부 발송 없음과 기존 회귀 검증을 수행한다.

현재 세션에 사용 가능한 Browser가 없어 실제 브라우저 화면 확인은 수행하지 못했다.
